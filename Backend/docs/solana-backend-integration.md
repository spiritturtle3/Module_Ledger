# Solana Backend Integration

## Scope

This integration is read-only. It adds Anchor account reading, PDA derivation, listing/escrow verification, Metaplex metadata retrieval, and an optional MongoDB transaction indexer. It does not expose marketplace initialization, treasury funding, user-key handling, or purchase transactions.

The IDL and generated TypeScript type in `src/blockchain/` were supplied by the Blockchain team. The supplied build metadata stated Anchor CLI 0.31.0 and Rust source commit `c2d34a62edc6d110079e472baadb1fd05983b9f0`. The Blockchain team had not yet confirmed localnet deployment correspondence or the R2 source deployment when these files were received.

## Environment

Add the following to `.env` (keep `.env` out of Git):

```env
SOLANA_CLUSTER=localnet
SOLANA_RPC_URL=http://127.0.0.1:8899
SOLANA_WS_URL=ws://127.0.0.1:8900
PROGRAM_ID=AuR4iqjMWbEmHTpKHyKcNbT3ggSAWrcZdudwCcjPuEBT
METADATA_PROGRAM_ID=metaqbxxUerdq28cj1RbAWkYQm3ybzjb6a8bt518x1s

MARKETPLACE_NAME=
COLLECTION_MINT=

MONGODB_URI=
SOLANA_INDEXER_POLL_INTERVAL_MS=15000
NFT_METADATA_TIMEOUT_MS=10000
IPFS_GATEWAY_URL=https://gateway.pinata.cloud/ipfs
```

`MARKETPLACE_NAME` must be the fixed name selected by the Blockchain team and must not exceed 32 UTF-8 bytes. `COLLECTION_MINT` is optional until the allow-list decision is final. If omitted, the Backend accepts any verified collection, matching the current program behavior.

The process remains localnet-only. Do not set Devnet or Mainnet. The Windows-to-WSL RPC route still needs a live connectivity test.

## New read endpoints

- `GET /api/solana/health` — validator reachability, version, genesis hash and program deployment presence.
- `GET /api/solana/marketplace` — Marketplace account, fee, treasury balance/rent minimum and rewards-mint decimals.
- `GET /api/solana/listings` — active listings filtered by Listing discriminator, marketplace PDA and verified vault balance.
- `GET /api/solana/listings/:mint` — one escrow-verified listing by NFT mint.
- `GET /api/solana/history?limit=50&status=active` — indexed listing and sale history (requires MongoDB).
- `GET /api/solana/sync/status` — indexer cursor and reset/error status.

Active listings are not returned unless:
1. The on-chain Listing account decodes with the bundled Anchor IDL.
2. Its PDA recomputes from the configured marketplace PDA and NFT mint.
3. Its associated token account is owned by the Listing PDA, has the same mint, and contains exactly one token.
4. Metaplex metadata contains a verified collection.
5. If `COLLECTION_MINT` is set, the collection matches it.

Missing NFT images are returned as `null`; no fake placeholder URL is generated by the Backend.

## Indexer

The optional MongoDB indexer polls `getSignaturesForAddress` with a saved cursor. It records listing, delist and purchase outcomes from confirmed successful program instructions. It stores lamport values as decimal strings.

If MongoDB or `MARKETPLACE_NAME` is absent, the indexer stays disabled and live read endpoints remain available. When the program disappears or the saved transaction cursor is missing, cached active listings are marked `orphaned`, prior sales are retained, and the indexer reports a reset/cursor status.

The indexer does not backfill more than 5,000 signatures in a single scan. A `partial` status means older history may need a manual backfill.

## Purchase and admin actions

No purchase endpoint or admin initialization/funding endpoint is exposed. The R2 relation is present in the supplied IDL and the indexer additionally checks that a successful purchase instruction's maker matches the maker recorded for the indexed listing. Keep purchase hidden until the Blockchain team confirms the R2-fixed binary is deployed and the end-to-end purchase tests pass.

## Installing dependencies

The Backend package now declares Anchor, Solana SPL Token, Metaplex Umi/Token Metadata, `bs58` and Mongoose dependencies. Because this ZIP was assembled without registry access, `package-lock.json` has not been regenerated here. In the Backend directory, run `npm install` once to update the lockfile and install the additions, then run `npm run typecheck`, `npm test` and `npm run build`.
